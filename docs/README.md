# 当前操作手册

本目录统一使用以下两份 Word，应用版本 1.4.0，手册更新日期 2026-10-25。

- [开发部署操作手册](航空载荷终端开发部署操作手册.docx)：系统准备与烧录、USB 认板、投屏、逐板 Wi-Fi 和 IP、应用安装、两板与五板配置、分布式、AI、重新开机和排错。
- [软件使用手册](航空载荷终端软件使用手册.docx)：面向使用者的打开软件、三类载荷操作、监看、任务协同、AI 报告、异常判断、记录与退出。

已经能正常启动并投屏的板子，从部署手册第 5 章开始；安装应用看第 7 章，连接多板网络看第 6 章。只有明确需要安装或恢复 OpenHarmony 系统时才做第 4 章整机烧录。

两份 Word 含可点击章节导航。PowerShell 命令为可选择复制的原生文字。未把 Word 渲染成图片；文档结构、命令语法和文件引用已检查。现场操作仍按手册逐项核对实际返回结果。
